# lobby

ログイン不要で使える、シンプルな共有チャットルームです。表示名だけ入力して、すぐに会話へ参加できます。

## 特徴

- Flask のアプリファクトリ構成
- インメモリで直近200件を保持
- 3秒ごとのポーリングで新着メッセージを取得
- ブラウザ側でメッセージをテキストとして描画し、入力内容を安全に表示
- GitHub Actions で lint、コンパイルチェック、Python 3.10〜3.13 のテストを実行

## 起動方法

Python 3.10 以上を用意し、プロジェクトのルートで実行します。

依存関係と仮想環境は [uv](https://docs.astral.sh/uv/) で管理します。

```bash
uv sync --dev
uv run flask --app app run --debug
```

ブラウザで http://127.0.0.1:5000/ を開いてください。

## テスト

```bash
uv run pytest
uv run ruff check .
```

依存関係を変更した場合は `uv lock` で `uv.lock` を更新し、ロックファイルもコミットします。

メッセージはプロセスのメモリ上にだけ保存されるため、アプリを再起動すると履歴は消えます。複数ワーカーでの永続運用にはデータベースや共有ストレージが必要です。
